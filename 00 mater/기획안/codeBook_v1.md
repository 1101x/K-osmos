## 자음 19 — `[element, stroke, tense]`

- **element**: 오행 (0=木, 1=火, 2=土, 3=金, 4=水) — 조음 위치
- **stroke**: 가획 단계 (0~3)
- **tense**: 병서/된소리 (0 또는 1)

| 자모 | element | 오행 | stroke | tense | 비고 |
|---|---|---|---|---|---|
| ㄱ | 0 | 木 | 0 | 0 | 기본 (木 — 혀뿌리가 목구멍 막는 모양) |
| ㅋ | 0 | 木 | 1 | 0 | ㄱ 가획 |
| ㄲ | 0 | 木 | 0 | 1 | ㄱ 병서 |
| ㄴ | 1 | 火 | 0 | 0 | 기본 (火 — 혀가 윗니 뒤에 붙는 모양) |
| ㄷ | 1 | 火 | 1 | 0 | ㄴ 가획 |

## 음절 구조

```
음절 = [ 초성[e,s,t], 중성[필순 시퀀스], 종성[ [e,s,t], ... ] ]
```

예: "왜" = `[[4,1,0], [0,1,2,0,2], []]`
예: "값" = `[[0,0,0], [2,0], [[2,1,0],[3,0,0]]]`
