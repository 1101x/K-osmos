# 🌌 한글 이름 추상화 프로젝트
**우리 모두는 각자 하나의 우주이다**  
음양오행을 바탕으로 한글을 재해석,
각자의 이름에 담긴 동양우주관을 보이려는 실험
자신이 얼마나 고유한 하나의 세계인지 지각
한글의 철학적 요소를 재밌게 가지고 놀았으면 좋겠다.

## 🎯 프로젝트 목적
**동양 우주관의 시각화**: 한글 자모에 담긴 음양오행 및 삼재(天·地·人)의 원리를 우주적 개체로 표현합니다.
**고유한 세계의 지각**: 이름과 단어가 가진 고유한 우주적 형상을 시각화하여, 자신만의 세계를 직관하게 합니다.**철학적 유희**: 한글의 구조적·철학적 요소를 재미있게 탐구하고 확장 가능한 예술/디자인 시스템을 구축합니다.



## 🪐 우주 시스템 구조 & 규칙
1. 자소 1개당 행성 1개
자소가 모인 음절 1개가 항성계가 됨
2. 어절 하나(이름 또는 단어) 가 성단을 이루고 문장으로 확장.
3. 이름 또는 문장이 모여 은하를 이룬다.

### 🔍 시스템 텍스트 처리 규칙 (미사용)
1. **어절 구분**: 띄어쓰기(` `)를 기준으로 성단을 생성합니다.
2. **문장 구분**: 마침표 + 띄어쓰기(`. `)를 기준으로 은하 단위로 확장합니다.
- 단, 성단 및 은하가 어절 중심일지 문장 중심일지 아직 미확정

## 우주 화면 ui 4뎁스 설명
1. 행성 클릭시 ; 음소 1개 확대 설명하는 행성 디테일 화면
2. 1음절 항성계 : 한글 제자 원리에 기반한 각 음소의 궤적을 그리는 화면
3. 1어절 성단 :  이름 또는 단어 하나가 모여있는 구성 성단 화면
4. 우리은하 : 문장 기준으로 우리은하 내 랜덤하게 배치되어있는 화면


## 폴더 트리 설명
1. 01 솔라시스템 폴더의 파일에서 전체 우주 구조 및 행성 텍스쳐 적용
2. 02 지오메트리 시스템 폴더의 파일에서 각 음절의 궤도 로직 반영
3. 03 레터 시스템 폴더의 파일에서 행성 클릭시 나오는 행성 디테일 화면용 디자인 적용
4. 04 갤럭시 지오메트리 폴더에 위 단계들 최종 합쳐진 화면 적용
